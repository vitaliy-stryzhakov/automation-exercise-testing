# Test Plan — Automation Exercise

**Project:** Automation Exercise  
**Document type:** Test Plan  
**Application under test:** https://www.automationexercise.com/  
**Test type:** Manual Testing

## 1. Project Overview

The purpose of this project is to practice manual software testing using the Automation Exercise website.

The project focuses on testing key website functionality, identifying defects, documenting test cases, and preparing bug reports.

## 2. Test Objectives

- Verify that the main website functionality works as expected.
- Identify functional and UI defects.
- Validate positive and negative user scenarios.
- Document test cases and actual results.
- Prepare clear and reproducible bug reports.

## 3. Test Scope

The following modules are included in the testing scope:

- Login and Logout
- Shopping Cart
- Products (product list, product details, search, categories and brands, product reviews)
- API (manual testing with Postman)

Additional modules may be included later.

## 4. Out of Scope

Automated testing, performance testing, and security testing are not included in the current project scope.

## 5. Test Approach

Testing is performed manually.

The following testing techniques and types are used:

- Functional Testing
- Positive Testing
- Negative Testing
- UI Testing
- Retesting (when applicable)
- Regression Testing (when applicable)
- API Testing (manual, using Postman)

## 6. Test Environment

- **Operating System:** Windows
- **Browser:** Microsoft Edge
- **Testing Type:** Manual Testing
- **Application:** Automation Exercise website
- **API testing tool:** Postman
